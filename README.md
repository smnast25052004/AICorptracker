## О проекте

AI CorpTracker — это прототип платформы для топ-менеджмента компаний, которая:

- автоматически собирает данные о ходе выполнения стратегических целей из корпоративных систем;
- анализирует структурированные и неструктурированные данные с помощью AI (эмбеддинги, семантический поиск);
- рассчитывает интегральный риск-скор по каждой стратегической цели на основе взвешенной факторной модели;
- предоставляет наглядные дашборды в Grafana (CEO Overview, Risk Analysis, Goals Detail) и административный интерфейс в Streamlit.

**Ключевые особенности:**
- локальная AI-модель (`all-MiniLM-L6-v2`) – данные не покидают контур заказчика;
- гибридное хранилище PostgreSQL + pgvector;
- модуль Decision Engine для автоматического пересчёта рисков и генерации рекомендаций;
- контейнеризация Docker Compose.

---
## Стек технологий:
1. Backend: FastAPI, Uvicorn, SQLAlchemy
2. База данных: PostgreSQL + pgvector
3. AI: sentence-transformers (all-MiniLM-L6-v2), scikit-learn
4. Визуализация: Grafana, Streamlit, Plotly
5. Контейнеризация: Docker, Docker Compose

Проект разработан в рамках выпускной квалификационной работы.

## Запуск проекта
1. Клонируйте репозиторий

git clone https://github.com/smnast25052004/AICorptracker.git
cd AICorptracker

3. Настройте окружение

cp .env.example .env

4. Запустите все сервисы через Docker Compose

docker-compose up -d --build

5. Загрузите демонстрационные данные

docker-compose exec api python -m seed.seed_data

6. Запустите анализ

curl -X POST http://localhost:8000/api/analysis/run

7. Настройте дашборды Grafana

python3 grafana/provision.py
